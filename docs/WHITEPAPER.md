# 第 1 章 執行摘要

企業正把「原始數據不出域」當作隱私保證——**推理軌**：客戶端跑模型前半段，把中間表徵送上雲；**訓練軌**：客戶端把訓練外包給雲端。兩條軌道都暴露於重構與劫持風險。本白皮書基於 **19 個實驗**（GPT-2 small+medium+large / Llama-3.2-1B / AG News+DBpedia+合成醫療 / 種子固定可重現）給出實測結論。結論的核心可壓縮為五點：軟件層的「安全出域」不存在（在 124M、355M、774M 和 Llama-1B 上均確認）；市場上多數隱私評估在測量儀器自己；存在唯一一條可測量的縫（分類任務加 8-9 bit 量化出域）；連訓練軌的隱蔽劫持策略也逃不過 CE 探針測量（訓練軌 exp13/13b 證明）；量化對 PHI 的壓制強於對普通詞的壓制（exp17 合成醫療筆記植入實驗：9-bit 下 PHI 恢復率比平均低 16pp，稀有實體低 20pp——碼本系統性優先吸收低頻實體）。

## 1.1 五個核心結論

**結論一：軟件層的「安全出域」不存在。** 凡保留任務效用的表徵，強攻擊者可恢復 93-99.9% 的原文 token（跨 GPT-2 與 Llama 家族均確認）；凡真正摧毀信息的操作，任務指標陪葬（PPL 膨脹 29-746 倍）。兩集群之間，經驗交集為空。這個負結果本身是 SA-RI 的存在理由——因為不存在 100 分的安全係數，所以必須有可量化的、有保鮮期的、可審計的已知風險。

**結論二：市場上多數隱私評估在測量儀器自己。** 同一表徵、同一攻擊網絡，僅換訓練損失（MSE 改為 CE），恢復率讀數相差 53-444 倍（本設置實測）。這解釋了為何大量「已驗證安全」的部署在強攻擊者面前全洩——他們的驗證儀器坐在自己的測量下限上，並未真正測量表徵的洩漏。SA-RI 的第一功能是把儀器校準，而不是再提供一個防禦產品。

**結論三：存在唯一一條可測量的縫。** 分類任務加 8-9 bit 量化出域——任務保持 84.4-97.4%（隨架構），token 洩漏壓制最高 76%。但天花板隨攻擊者容量開放上升（0.36→0.42→0.47 未收斂），且類別信息照洩（標籤恢復 85.9%）。縫的寬度有架構依賴（GPT-2: 0.36-0.39；Llama: 0.22）。這條縫我們分類為 AMBER 級威脅模型相依的風險降低，不是隱私。

**結論四：連訓練軌的隱蔽劫持策略也逃不過測量。** 訓練期劫持攻擊中，最隱蔽的變體恰恰是表徵保持滿洩漏的變體（SIA：恢復率 97%，任務正常）——唯一能偵測的儀器是我們的 CE 探針，不是任務指標。這是 SA-RI 雷達圖 R6 軸的存在依據：形狀騙不了，單分數被騙。訓練軌不是推理軌的附屬——它有獨立的 signature 與獨立的合規路徑（見 §3.6 與 §4.5）。

**SA-RI 的定位**：不是又一個防禦產品，是風險的通用語言。SA-RI 的報告是合規證據，不是安全承諾。測量權在 SplitAudit（錨點校準的探針電池），決策權在機構（自定閾值），監督權在監管（認證記錄審計）三分。

# 第 2 章 為什麼需要實測：三個被親手戳破的幻覺

## 2.1 幻覺一：「深度是防禦」

標準 MSE 探針測出的恢復率隨深度從 0.096 降到 0.003——這是儀器的測量下限，不是表徵的洩漏下限。CE 型探針重測全部深度：恢復率平坦在 0.96-0.999。兩條曲線的差，在第 8 層是 444 倍（0.22% 對 97.6%，本設置實測）。深度確實消除了線性可讀性（零參數餘弦探針從 0.069 降到 0.005，降 14 倍），但可學習解碼性紋絲不動。深度的正確描述：混淆，不是隱私。

|---|---|---|---|---|---|---|

## 2.2 幻覺二：「指標達標 = 防禦生效」

我們復現了最強的對抗 adapter 防禦並施加三重檢驗。距離型指標增益 1.5-3.2 倍（宣稱成立）；表徵位移達原範數的 75-247%（防禦在大力撥動幾何）；但 Token 恢復率 0.9684±0.0025 vs 基線 0.9676——不動。有一格通過了文獻 Pareto 判據（效用大於 0.95 且 MSE 大於 3 倍）而實際零防護。判據本身會選出可被操縱的格。CE 指標也可被範數膨脹操縱。唯一不可操縱的：**餘弦檢索的 token 恢復率**。

> 指標層級：MSE 可灌水（3.2 倍增益不動恢復率）< CE 可灌（範數膨脹）< 餘弦恢復率不可灌（13 實驗驗證，oracle 閉合）。

## 2.3 幻覺三：「上一次驗證通過 = 現在安全」

蜜罐實驗：修正兩個儀器錯誤後，「30 倍隱私增益」反轉為負防禦。訓練期劫持也有兩個 signature：FSHA 型（無主任務橋）：任務崩塌至 0.29，恢復率降至 0.76——雙輸，易檢測；SIA 型（隱蔽）：任務保持 0.87 正常，恢復率 97.0%——滿洩漏，難檢測。R-M 等價於 S-M（差小於 0.02）：洩漏由 alpha 決定，不是訓練模式。

> 本節的教訓統一成一句：隱私評估的失敗模式不是「測錯了數字」，是儀器本身坐在測量下限上。SA-RI 的第一功能是把儀器校準——四錨點校準就是這個功能的工程實現。

# 第 3 章 SA-RI 是什麼：測量協議與指標結構

## 3.1 數學定義

**Safety(S; budget) = max over probes × max over C ⊆ nodes of R(probe, C, S; budget)**——所有合謀子集 × 所有探針層級中最大恢復率，附帶攻擊者預算參數。其中 S 為部署方案（split_depth、N_shards、shard_axis、VQ_bits、owner_topology、routing），budget 為（樣本量、epochs、容量、查詢量、輔助語料規模），是一級協議字段。**超額洩漏 = 實測恢復率 減 環境基線。**

## 3.2 威脅模型：雙軌

| 軌道 | 客戶端動作 | 攻擊者位置 | 可見內容 |
|---|---|---|---|
| 推理軌 | 客戶端 head 運算後表徵 z 出域 | 誠實但好奇的 server | 只看 z |
| 訓練軌 | 客戶端把訓練外包 | 惡意 server（FSHA / SIA 劫持） | 訓練過程控制權 |

表 2：雙軌威脅模型。兩軌的攻擊者能力、可見內容、偵測方法均不同，必須分別評估。

## 3.3 探針階層與四錨點校準

探針分四階：Tier 0 線性地板（零參數餘弦對齊，下界參照）；Tier 1 MSE fresher（重建表徵，文獻默認，測量下限警示）；Tier 2 CE 解碼器（對 ground-truth token，主儀器）；Tier 3 序列解碼器（雙向 transformer，容量可縮放，天花板追蹤）；Tier + 自適應與跨域（co-training、異域重訓，防滯後假象）。

**v3.3 新（exp18b）**：探針訓練存在 ~7pp run-to-run 方差；任何 verdict 前須 3 seed 以上平均——方差所致的 t5−t1 大間距讀數由工具自動拒判（INCONCLUSIVE），不做猜測。

## 3.6 訓練軌 SA-RI 協議：FSHA / SIA / R-M 三 signature

推理軌攻擊者只看表徵 z；訓練軌攻擊者控制訓練過程。訓練外包在金融、醫療、聯邦學習場景普遍存在——醫院把醫學影像模型訓練外包、銀行把風控模型訓練外包、聯邦學習參與方把本地梯度上傳。這些場景下攻擊者不是 honest-but-curious 的 server，而是**惡意 server**，能透過訓練過程劫持表徵生成。訓練軌 SA-RI 協議識別出三個獨立 signature，每個 signature 對應獨立的偵測與處置路徑。

### 3.6.1 FSHA signature：雙輸型（易偵測）

FSHA（Feature Space Hijacking Attack）無主任務橋——攻擊者直接把表徵劫持到自己的解碼器，完全脫離主任務。實測（exp13 文本域）：任務崩塌至 0.291，恢復率 0.7562。這是**雙輸** signature——攻擊者拿到了表徵但任務死了，主任務指標立即暴露異常。偵測難度：低。任務崩塌就是警報，任何任務監控都能抓到。

### 3.6.2 SIA signature：隱蔽型（難偵測，唯 CE 探針可抓）

SIA（Sustainable Inference Attack）加主任務橋——攻擊者一邊保留主任務可運行，一邊偷偷劫持表徵。實測（exp13）：任務保持 0.873 正常，恢復率 0.9695——滿洩漏加任務正常。這是**隱蔽** signature——任務指標完全無法偵測。唯一能偵測的儀器是 CE 探針（probe t1=0.9725），它獨立於任務指標，直接量度表徵可恢復性。

> SIA 的合規險惡性：若客戶用任務指標驗收訓練外包供應商——任務正常 0.873，驗收通過。但表徵已被滿洩漏（97%）。這就是 SA-RI R6 軸的存在理由：R6 = 任務正常而探針異常，這個尖刺在合成分數中消失，但雷達圖立刻暴露。

### 3.6.3 R-M ≡ S-M signature：洩漏由 alpha 決定，非訓練模式

R-M（Retain-Main）修復實驗（exp13b）：嘗試透過保留主任務梯度路徑修復 SIA。結果：probe t1=0.9725（與 S-M 等價，差 0.0008 在噪聲範圍內），acc=0.892（+1.6pp vs SIA）。**結論**：洩漏由 alpha（劫持強度）決定，不是訓練模式——R-M 與 S-M 在 probe 上完全等價，修復主任務並未降低洩漏。這個 signature 的合規含義：不能靠「換訓練模式」解決劫持，必須靠 CE 探針偵測加拒絕外包。

**表 5b：訓練軌三 signature 對比**

| Signature | 任務指標 | CE 探針讀數 | 偵測難度 | 合規處置 |
|---|---|---|---|---|
| FSHA（雙輸） | 0.291（崩塌） | 0.7562 | 低（任務監控即可） | 任務警報觸發，拒絕外包供應商 |
| SIA（隱蔽） | 0.873（正常） | **0.9695** | 高（唯 CE 探針可偵測） | CE 探針定期抽測，超閾則降級 |
| R-M ≡ S-M（修復無效） | 0.892（正常） | 0.9725 | 高（同 SIA） | 不可靠訓練模式修復，必須 CE 偵測 |

### 3.6.4 CE 探針 vs 任務指標：為什麼任務指標騙不了 CE 探針

任務指標（accuracy、PPL）測的是主任務可運行性——攻擊者保留主任務橋時，任務指標永遠正常。CE 探針測的是表徵可解碼性——獨立於主任務，直接從表徵恢復 token。兩者測的不是同一個量。這就是 SIA 隱蔽 signature 能騙過任務指標但騙不過 CE 探針的根本原因。

**表 5c：CE 探針 vs 任務指標對比**

| 指標類型 | 測量對象 | SIA 場景讀數 | 能偵測 SIA？ | 可灌水性 |
|---|---|---|---|---|
| 任務 accuracy | 主任務可運行性 | 0.873（正常） | 否 | — |
| 任務 PPL | 語言建模品質 | 正常範圍 | 否 | — |
| 梯度掩蔽 GM | 梯度洩漏量 | 0.59-0.77（看似有掩蔽） | 否（artifact） | 可被人為操縱 |
| CE 探針恢復率 | 表徵可解碼性 | **0.9695**（滿洩漏） | 是 | 不可灌（oracle 閉合） |
| 餘弦檢索恢復率 | token 身份檢索 | 0.9695 | 是 | 不可灌（13 實驗驗證） |

表 5c：SIA 的合規險惡性在於前三行全部正常——只有 CE 探針與餘弦檢索能暴露。這也是 SA-RI 拒絕合成分數的原因：若把任務指標與 CE 探針合成一個分數，SIA 會通過驗收。

### 3.6.5 訓練軌認證框架：外包決策門控 + CE 探針定期抽測

訓練軌沒有「量化 9-bit 出域」這種軟路徑——訓練外包要嘛走、要嘛不走。但 SA-RI 仍可提供訓練軌認證框架，由三個組件構成：

**組件一：外包決策門控。** 訓練外包前必須通過 SA-RI 風險評估：若訓練數據含特殊類別信息（醫療診斷、金融評級），直接 RED 級——禁止外包，必須本地訓練或走 TEE 加聯邦學習。若數據為一般類別，AMBER 級——可外包但須 CE 探針監控。

**組件二：CE 探針定期抽測。** 外包供應商交付模型後，客戶用 CE 探針對表徵抽測——抽測頻率同推理軌訂閱邏輯（季測加事件觸發）。抽測恢復率超過閾值（建議 AMBER 上限 0.6）則觸發降級：拒絕該模型版本、要求供應商重新訓練或終止合約。

**組件三：降級路徑。** 訓練軌降級路徑有四條：(a) 本地訓練（成本最高、隱私最強）；(b) TEE 加聯邦學習（成本中、隱私強，依賴硬體）；(c) 同態加密訓練（成本高、延遲大、目前工程可行性低）；(d) 拒絕外包、改用本地小模型（成本最低、效用受限）。SA-RI 不選擇路徑，只量化風險——選擇權在機構合規委員會。

### 3.6.6 SplitRisk `--baseline sia` 對照模式：可復現 exp13 協議

SplitRisk v0.2.1 包含 `--baseline sia` 對照模式（W4 上線），可復現 exp13 協議——在客戶端 head 與 server tail 之間注入 SIA 劫持，然後用 CE 探針偵測。驗收標準：probe t1 與 exp13 S-M 數據誤差 < 0.5pp，acc 與 exp13 主任務誤差 < 1.5pp。注意事項：exp13 的 retain_graph 共享圖問題在 PyTorch 1.x 下會炸——須用 PyTorch 2.x 的 detach 加 grad 顯式分離。回滾預案：若 SIA 對照模式有工程問題，先回滾到 exp2e 對照模式（已驗證）。

## 4.1 三檔路由

RED 直接走 TEE（硬體檔：表徵不落地明文，延遲約 1.1 倍）或本地（底線檔）；AMBER 走 9-bit 量化出域（統計檔：唯一軟件路徑）；GREEN 實務上目前等於紅燈——只有任務死亡區會出現真正的 GREEN。AMBER 認證的精確邊界：任務保持 84.4-97.4%（隨架構）；Token 超額洩漏最高 +16pp（削減 76%）；天花板開放 0.36→0.42→0.47 未收斂；標籤照洩 85.9%（類別即敏感場景等於紅燈）；縫寬有架構依賴（Llama 更窄）；語料覆蓋 AG News / DBpedia / Llama（per-deployment 校準強制）。

## 4.4 訂閱邏輯：保鮮期的科學依據

攻擊者容量單調上升——容量階梯 3 層到 6 層解碼器多榨 6.5pp。訂閱採基礎季測加事件觸發，頻率依容量階梯斜率，**非每週**。保鮮期隨讀數輸出——這是 SA-RI 與其他評估工具最大的差異：我們不賣「一次性安全認證」，賣「有保鮮期的合規證據流」。

**事件觸發的現實案例（2026-09）**：多家前沿模型廠商的威脅情報報告與 CISA/NSA/FBI 聯合公告證實——用戶以為只發送給某一模型的請求，可能未經告知被後端轉送到第三方模型；針對前沿模型的工業級蒸餾已被官方定性。攻擊者容量正在被產業化、貨幣化——這正是 SA-RI「季測+事件觸發」訂閱邏輯的現實印證：新攻擊族公開或重大事件發生，即觸發重測。

## 4.5 訓練軌合規場景：訓練外包、聯邦學習、醫院 / 銀行跨境

推理軌合規聚焦於表徵出域的風險量化；訓練軌合規聚焦於訓練過程控制權外包的風險量化。三個典型合規場景：訓練外包（單一機構把訓練交給雲端供應商）、聯邦學習（多機構把本地梯度上傳聚合）、跨境訓練（醫院 / 銀行把敏感數據訓練外包給境外雲）。三場景的核心差異：攻擊者能力從「只看表徵」升級為「控制訓練過程」，因此偵測儀器必須從任務指標升級為 CE 探針（見 §3.6.4）。

**表 7b：訓練軌四個合規場景**

| 場景 | 典型客戶 | 錨定法規 | SA-RI 角色 | 認證路徑 |
|---|---|---|---|---|
| 訓練外包 | 金融風控、推薦系統 | DORA ICT 第三方風險 | CE 探針抽測供應商交付模型 | AMBER 級 + 季測 + 交付驗收 |

**訓練軌與推理軌的合規協同。** 訓練軌認證產出的「模型版本」會在推理軌部署——所以訓練軌 CE 探針抽測記錄必須與推理軌 SA-RI 報告共享同一個認證編號空間。客戶合規委員會可從訓練軌認證記錄追溯到推理軌部署記錄，形成完整的「模型血統鏈」。

> 訓練軌合規的險惡性：若客戶只用任務指標驗收訓練外包供應商——SIA 場景下任務正常 0.873、驗收通過、表徵已滿洩漏 97%。SA-RI 的 CE 探針是把這個隱蔽劫持變成可量化、可審計、可拒收的合規證據。

## 4.6 AMBER 適用邊界與檢測粒度（v3.3 新）

**AMBER 適用邊界（誠實條款 7）**：9-bit 量化出域是唯一軟件路徑，但僅在同時滿足四條件時適用：(a) 標籤不含敏感類別；(b) 任務輸出不含敏感內容；(c) codebook 統計特徵不構成對客戶群體的指紋；(d) 數據量大到本地推理不可行。排序、徵信評分、醫療診斷等「類別即敏感」場景不適用 AMBER——直接紅燈，走本地或 TEE。跨家族數據（exp19）顯示縫寬有架構依賴（Llama 上更窄），AMBER 判定不可跨架構外推。

**檢測粒度（誠實條款 8）**：SA-RI 是**部署級認證，不是 query 級檢測**。一次審計（約 2 GPU 小時）覆蓋同一 head 與量化配置下的所有 query；季度續測（約 30 分鐘）加事件觸發續測；年成本約 6.5 GPU 小時。

**Codebook side-channel（誠實條款 9）**：9-bit VQ codebook 出域不增加 token 恢復風險（已測），但其向量分佈可能洩露訓練數據的統計特徵。部署時應評估 codebook statistical leakage，或以通用語料擬合 codebook。

# 第 6 章 誠實條款（v3.3，十條，不可關閉，寫進 license）

1. 攻擊者預算隨每個讀數輸出；單份下降不等於隱私（容量稀釋）——合謀上限由位元率決定。
2. 天花板標註開放上界：0.36→0.42→0.47 未收斂。任何 AMBER 認證必須附保鮮期與容量階梯版本。
3. entity 已測（合成，機制級，有利）：PHI 被量化差異化壓制（ratio 0.625），指紋假說否證；醫院分佈仍屬部署工作。
4. 語料×規模×家族已在實測點確認（AG News/DBpedia/合成醫療 × 124M/355M/Llama-1B）；環境基線隨規模、域、家族變化（0.317→0.415），per-deployment 校準強制。
5. R2 位元率鎖不死：9-bit 量化鎖不死標籤——類別即敏感場景必須直接紅燈。
6. 紅燈的解法是 TEE / 本地：本工具測量風險，不消除風險。
7. AMBER 適用邊界四條件（見 §4.6）：四條件不滿足即紅燈；縫寬有架構依賴，不可跨架構外推。
8. 檢測粒度：部署級認證非 query 級檢測；年成本約 6.5 GPU 小時（見 §4.6）。
9. Codebook side-channel：碼本出域不增 token 恢復風險，但統計特徵須評估（見 §4.6）。
10. 閉源 LLM 不適用（無中間表徵可測）；探針訓練有 ~7pp run-to-run 方差（exp18b）——多 seed 平均為協議要求，單次大間距讀數由工具拒判。

誠實條款十條是 SA-RI 寫進 license 不可關閉的條款。把短板寫在臉上反而是護城河——客戶合規委員會看的是「你知道自己不知道什麼」，不是「你宣稱全知」。誠實姿態對接監管對程序正義的要求。

# 結語

這個世界不需要又一個「保證安全」的承諾。SA-RI 做到的是：讓每一次出域決策帶著**量化的、有保鮮期的、可審計的**已知風險上路。保險公司不因為「沒有絕對安全」而拒保——它按防盜等級定價。SA-RI，就是拆分學習與推理的防盜等級。
